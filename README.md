# 二手房交易平台 (Second-hand House Trading System)

这是一个基于 Spring Boot 3 和 Vue 3 开发的现代二手房交易管理系统。

## 🛠 技术栈
- **Frontend**: Vue 3 + Vite + Element Plus + Tailwind CSS
- **Backend**: Spring Boot 3 + MyBatis Plus + JWT Security
- **Database**: MySQL 8.0 + Redis 7
- **DevOps**: Docker + Docker Compose

## 📂 项目结构
```text
.
├── backend                 # 后端源码 (Spring Boot)
│   ├── src/main/java       # Java 代码
│   │   └── com/example/housetrading
│   │       ├── common      # 公共返回结果与工具类
│   │       ├── config      # 配置类 (Security, Redis 等)
│   │       ├── controller  # 接口控制器
│   │       ├── entity      # 数据库实体
│   │       ├── mapper      # MyBatis Mapper 接口
│   │       └── service     # 业务逻辑层
│   └── pom.xml             # 项目依赖管理
├── frontend                # 前端源码 (Vue 3 + Vite)
│   ├── src
│   │   ├── layouts         # 页面布局
│   │   ├── router          # 路由配置
│   │   ├── store           # 状态管理 (Pinia)
│   │   └── views           # 页面组件
│   └── package.json        # 前端依赖配置
├── db                      # 数据库初始化脚本
│   └── init.sql            # 数据库结构及演示数据
├── docker-compose.yml      # Docker 编排配置
└── README.md               # 项目说明文档
```

## How to Run
1. 确保您的电脑已安装并启动 **Docker Desktop**。
2. 在项目根目录下打开终端，执行：
   ```bash
   docker compose up
   ```
3. 等待所有服务启动完成。

## Verification
按照以下步骤可快速验证核心系统功能：
1. **登录系统**: 使用 `user` 账号登录，访问前台并浏览首页丰富的房源数据。
2. **房源详情与互动**: 点击任意房源进入详情页，测试“在线咨询”和“收藏”功能。然后在左栏用户菜单查看“我的收藏”。
3. **预约看房**: 对房源发起看房预约。随后退出改用 `landlord` 账号登录，在“预约管理”中查看并处理该预约请求（同意/拒绝）。
4. **房东发布房屋**: 作为 `landlord` 发布一套新房源。
5. **管理员审核**: 退出改用 `admin` 账号登录。你将在顶部通知铃铛看到待处理的通知。进入“房源审核”页面，你可以尝试点击“通过”或者点击“驳回”并输入驳回理由。
6. **状态流转验证**: 切回 `landlord` 账号，进入“房源管理”，查看刚发布的房源状态是否已变为“展示中”或“已驳回”（将鼠标悬停在“已驳回”标签上可查看驳回原因）。


## 🏗️ 系统功能模块

### 1. 登录与认证模块
- **用户登录**: 支持不同角色（用户、房东、管理员）的安全登录。
- **用户注册**: 提供新用户账号创建功能。


### 2. 前台用户功能模块
- **首页展示**: 轮播图、推荐房源及最新公告展示。
- **房源浏览**: 支持按区域、价格、户型等条件筛选搜索房源。
- **房源收藏**: 用户可将心仪房源加入个人中心收藏夹。
- **看房预约**: 在线选择预约时间，与房东初步沟通。
- **评论与评分**: 对已看房源进行真实评价与打分。

### 3. 房东功能模块
- **房源发布**: 填写详细房源信息并上传图片发布。
- **房源管理**: 对已发布的房源进行修改、下架或删除操作。
- **预约管理**: 处理用户的看房请求，安排带看。
- **合同管理**: 在线生成、查看及管理电子租赁合同。

### 4. 后台管理模块
- **用户管理**: 查看、禁用或删除系统用户。
- **房东管理**: 审核房东资格，管理房东列表。
- **房源管理**: 审核新发布的房源，过滤非法信息。
- **预约/合同管理**: 监管全站预约流程及合同签署状态。
- **系统公告**: 发布、发布及管理全站公告信息。
- **支付管理**: 记录并监管平台内的交易流水。

### 5. 系统支撑模块
- **权限控制**: 基于 RBAC 模型实现严格的页面与接口访问权限。
- **数据库管理**: 数据持久化存储、备份及高性能索引优化。
- **系统日志**: 记录关键操作行为及异常日志，确保护根。

## 🎨 系统设计方案

### 1. 用户与权限管理设计
- **角色划分**: 实现管理员（全权限）、房东（房源与预约管理）和普通用户（浏览与预约）三类核心角色。
- **权限控制**: 采用 Spring Security + JWT 方案，实现基于 URL 的细粒度权限校验。
- **安全性**: 密码采用 BCrypt 强哈希加密存储，有效保障用户数据安全性与操作规范性。

### 2. 数据库与数据安全设计
- **存储架构**: 使用 MySQL 进行核心业务数据的持久化存储，合理设计 10+ 张关联数据表结构。
- **一致性保证**: 充分利用数据库事务与外键约束，确保房源、预约、合同等核心数据的一致性与完整性。
- **性能优化**: 结合 Redis 缓存热门房源数据与用户 Session，显著降低数据库 I/O 压力并提高系统响应效率。

### 3. 系统测试与优化
- **功能测试**: 对登录、注册、房源发布、预约看房等核心链路进行全覆盖测试，确保业务逻辑的正确性。
- **性能优化**: 通过索引优化与代码重构，降低接口响应时延；使用 Docker 资源限制确保系统运行的稳定性。
- **稳定性保障**: 完善的异常处理机制与日志监控，确保系统在并发访问下仍能保持高可用性。

## ✨ 核心特性
- **容器化部署**: 一键启动整个全栈环境，无需本地安装各种环境。
- **角色权限控制**: 基于 JWT 和 Spring Security 实现的细粒度 RBAC 权限模型。
- **现代化 UI**: 极致审美的 Element Plus + Tailwind 组合，支持响应式布局。
- **业务闭环**: 涵盖房源发布、审核、预约、看板等核心业务逻辑。
- **反馈设计**: 完善的 Loading 状态、骨架屏以及定制化的删除确认对话框。
